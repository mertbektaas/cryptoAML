# Tests

- `fixtures`: küçük ve tekrar kullanılabilir girdiler.
- `golden-datasets`: beklenen sonuçları sabitlenmiş veri setleri.
- `contract`: RPC, event, API ve webhook sözleşme testleri.
- `integration`: servisler arası veri akışı testleri.
- `performance`: ingestion, API ve graph bütçe testleri.
- `security`: auth, RBAC, tenant ve dependency testleri.
