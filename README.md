# cryptoAML
Platform, halka açık blockchain verisini sürekli olarak toplar ve kanonik bir modele dönüştürür; adres, işlem, token, smart contract ve cross-chain köprü ilişkilerini graph üzerinde analiz eder. Sonuç; tarama API'leri, araştırma ekranı, açıklanabilir risk skorları, alarmlar ve vaka yönetimiyle sunulur.
